# Architecture Decision Records

This directory stores permanent records of significant architectural decisions.

Each record should explain:

- The decision
- The context
- The alternatives considered
- The consequences
- The date and status

Planned records include:

- Genre-neutral engine
- Authority model
- ActionContext
- ActionResult
- Closed-world AI
- Spatial model
