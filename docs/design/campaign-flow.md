# Campaign Flow

Campaign creation should eventually allow players to choose:

1. Genre
2. Ruleset
3. Setting
4. Presentation style
5. Content Safety Profile
6. Spatial mode
7. Campaign complexity
8. Characters

A campaign configuration may eventually resemble the following:

    {
      "id": "campaign_001",
      "rulesetId": "near_future_v1",
      "settingId": "blackwall_neon_v1",
      "contentProfileId": "original_content_only",
      "presentationId": "neon_noir",
      "spatialMode": "theatre_of_mind"
    }

These selections should configure the engine without changing core source code.
