# Modular Engine

Blackwall Runner is a genre-neutral simulation engine rather than a game tied permanently to one setting.

## Separation of responsibilities

- Rulesets define mechanics.
- Settings define fiction.
- Presentation packages define narrative style and interface language.
- Content Safety Profiles constrain generated content.
- Interfaces allow players to interact with the engine.

The core engine must not require cyberpunk, fantasy or space-opera terminology.

Campaigns should select their ruleset and setting through configuration rather than through changes to engine code.
