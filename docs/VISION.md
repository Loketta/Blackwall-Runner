# Blackwall Runner Vision

Blackwall Runner is a persistent tabletop RPG simulation engine designed for solo and group play.

The engine separates player intention, mechanical truth, world consequences and narrative presentation.

## Core principles

- Player owns intention.
- Engine owns truth.
- World owns consequence.
- AI owns presentation.

## Product direction

Blackwall Runner should support multiple rulesets, settings and interfaces without requiring changes to the core simulation engine.

The initial target genres are:

- Near-future cyberpunk
- Fantasy
- Space opera

The engine should eventually support:

- Plain-English player interaction
- Persistent shared worlds
- Contextual action duration
- Autonomous NPC schedules
- Dialogue, quests and combat
- Solo and multiplayer campaigns
- Browser and Discord interfaces
- Optional tactical battlemaps
- Commercially safe setting and ruleset packages

The AI is not the authority over game state. It interprets player intentions and presents validated outcomes produced by the engine.
